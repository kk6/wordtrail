# 一覧と削除

パネル上部の **一覧** で、登録した単語が新しい順に並ぶ。各行には見出し語、▶、文脈の件数（`文脈 1`）だけが出る。行をクリックすると、その単語の編集画面に移る。一覧から開いた編集画面には今の文の欄がなく、見出し語は書き換えられず、保存してもメモだけが書き換わって文脈は増えない。この画面にだけ **削除** が出て、確認のダイアログで承認したときだけ単語帳から消えて一覧に戻り、一覧に「『run』を削除しました。」のように出る。ナビのボタンは、編集画面では **一覧**、一覧では **戻る** で、**戻る** は最後にダブルクリックした単語を出す。

## Sub-features

- `list-order` は、登録した日時の新しい順に並べる。
- `list-row` は、行に見出し語、▶、文脈の件数だけを出し、▶ では編集画面に移らない。
- `list-open` は、行のクリックで、今の文の欄のない編集画面に移り、メモとこれまでの文脈を出す。書けるのはメモだけ。
- `list-save` は、一覧から開いた単語の保存で、メモだけを書き換え、文脈を増やさない。
- `list-nav` は、一覧から開いた編集画面の **一覧** で一覧に戻り、一覧の **戻る** で最後にダブルクリックした単語を今の文と一緒に出す。ダブルクリックした単語がまだなければ、**戻る** は押せない。
- `list-delete` は、一覧から開いた編集画面にだけ **削除** を出し、確認で承認したときだけ消して一覧に戻り、削除したと出す。

## How to get to it (user POV)

- パネル上部の **一覧** をクリックする。編集の画面に戻るときは **戻る** をクリックする。
- 一覧の行をクリックすると、その単語の編集画面に移る。

## Driving it with verify.mjs

Preconditions:

- `verify.mjs doctor` が `doctor: OK` を出す。
- `en.wiktionary.org` につながる（登録で意味が入るのを待つため）。
- ジャーニーの最初に `openPanel` でパネルのページを開いておく。

- **登録。** `#ubiquitous`、`#idempotent`、`#deprecated` の順にダブルクリックし、それぞれ意味が入るのを待って保存する。`idempotent` だけ、メモに `冪等` と書いてから保存する。ダブルクリックで開いた編集画面には `#delete` が出ない。
- **新しい順と行。** `#toggle-list` をクリックする。`verify.mjs run list` で、`#words > li` の `data-headword` が `deprecated`、`idempotent`、`ubiquitous` の順になり、`idempotent` の行の文字が `idempotent ▶ 文脈 1` になることを確かめる。
- **▶ では移らない。** `idempotent` の行の `.speak` をクリックしても、一覧のまま。
- **一覧から開く。** `idempotent` の行の `.count` をクリックする。編集画面に `idempotent`、メモ `冪等`、これまでの文脈 1 件が出て、`#current` は出ず、ラベルは `Wiktionary` と `メモ`、書ける欄は `note` だけで、`#delete` が出る。
- **メモだけの保存。** メモを書き換えて `#save` をクリックする。保存の中身のメモが変わり、文脈は 1 件のまま、編集画面のまま。
- **ナビ。** `#toggle-list` が `一覧` で、押すと一覧に戻る。もう一度押す（`戻る`）と、`deprecated` が今の文と一緒に、書き換えられる見出し語で出る。
- **削除。** 一覧で `ubiquitous` の `.open` をクリックし、`#delete` で確認をキャンセルすると、消えずに編集画面のまま。もう一度押して承認すると、一覧に戻り、`ubiquitous` だけが一覧と保存の中身から消え、`#list-status` が `「ubiquitous」を削除しました。` になる。
- **戻り先がないとき。** 拡張を読み込み直す（セッションのストレージが消える）。一覧から `idempotent` を開き、`一覧` を押すと、`戻る` が押せない。
- **証跡。** `list-page.png` と `list-panel.png` に、削除した後の一覧が残る。

## Gotchas

- 一覧の項目は `#words > li` で数える。
- 確認のダイアログは `clickInPanel(selector, { dialog: true })` で承認、`{ dialog: false }` でキャンセルする。指定しないと、ダイアログが出たまま止まる。
- 行のどこをクリックしても開くが、`.speak` だけは開かない。行を開くときは `.open` か `.count` をクリックする。
