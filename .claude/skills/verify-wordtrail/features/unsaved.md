# 書き換え中の内容を守る

パネルで見出し語かメモを書き換えると、保存ボタンの横に「未保存」と出る。そのまま別の語をダブルクリックすると、変更を捨てるかの確認が出て、キャンセルすると書き換えた内容が残る。Wiktionary の意味が入っただけで、まだ何も書き換えていない新規の語からは、確認なしで切り替わる。Wiktionary の欄は書き換えられないので、引いた結果は書き換えに数えない。一覧の行のクリックと、一覧の **戻る** で編集画面の内容が置き換わるときも、同じ確認が出る。**一覧** を押しただけでは内容は置き換わらないので、確認は出ない。

## Sub-features

- `unsaved-mark` は、書き換えると「未保存」と出し、保存すると消す。
- `unsaved-confirm` は、書き換え中に別の語をダブルクリックすると確認を出し、キャンセルなら今の内容を残す。
- `unsaved-replace` は、一覧の行のクリックと、一覧から開いた語での **戻る** でも確認を出す。読書中の語のまま一覧を見て **戻る** と、書き換えた内容が残り、確認は出ない。
- `unsaved-skip` は、書き換えていない語（新規でも登録済みでも）からは確認なしで切り替える。

## How to get to it (user POV)

- 単語をダブルクリックし、パネルで見出し語かメモを書き換えてから、ページで別の単語をダブルクリックする。
- 書き換えたまま **一覧** を押し、行をクリックするか、**戻る** を押す。

## Driving it with verify.mjs

Preconditions:

- `verify.mjs doctor` が `doctor: OK` を出す。
- `en.wiktionary.org` につながる（意味が入るのを待つため）。
- `openPanel` でパネルを開いた後、`watchPanelDialogs` で確認のダイアログを記録する。

- **書き換えていない。** `#ubiquitous` をダブルクリックして意味が入った後、`#unsaved` は隠れている。`#idempotent` をダブルクリックすると、確認なしで切り替わる。
- **書き換える。** メモに `冪等` と書くと、`#unsaved` が出る。
- **キャンセル。** 確認をキャンセルにして `#deprecated` をダブルクリックすると、確認が 1 回出て、見出し語は `idempotent`、メモは `冪等` のまま。
- **承認。** 確認を承認にして `#deprecated` をもう一度ダブルクリックすると、`deprecated` に切り替わる。
- **保存の後。** メモを書いて保存すると `#unsaved` が隠れ、`#ubiquitous` には確認なしで切り替わる。
- **一覧。** `ubiquitous` のメモを書いて `#toggle-list` を押しても、確認は出ない。確認をキャンセルにして `deprecated` の行を開くと、確認が出て一覧のまま。`戻る` を押すと、確認なしで `ubiquitous` とメモが残っている。
- **一覧から開いた語。** 承認にして `deprecated` を開き、メモを書き換える。キャンセルにして `#idempotent` をダブルクリックすると確認が出て、メモが残る。`一覧` から `戻る` を押すと確認が出て、一覧のまま。承認にして `戻る` を押すと、最後にダブルクリックした `idempotent` が出て、`deprecated` のメモは保存した `非推奨` のまま。`verify.mjs run unsaved` で全項目を確かめる。

## Gotchas

- 確認は `chrome.storage` の変化を受けたパネルが `confirm()` で出す。ダブルクリックそのものは取り消せないので、キャンセルしても、登録済みの語なら文脈は足され、パネルを開き直すと新しい語が出る。
- パネルを閉じるときの未保存の警告はない。
