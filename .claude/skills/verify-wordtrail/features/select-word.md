# 単語を選ぶ

英語のページで単語をダブルクリックすると、タブの右側のサイドパネルが開き、その単語が表示される。英単語 1 語でない選択（日本語、数字、複数の語）では何も起きない。

## Sub-features

- `select-open` は、パネルが閉じた状態からのダブルクリックでパネルを開き、単語を出す。
- `select-switch` は、パネルが開いた状態で別の単語をダブルクリックすると、表示を切り替える。
- `select-ignore` は、英単語 1 語でない選択ではパネルを開かない。
- `select-icon` は、ツールバーのアイコンでパネルを開く。

## How to get to it (user POV)

- 読んでいるページで単語をダブルクリックする。
- ツールバーの Wordtrail のアイコンをクリックする。

## Driving it with verify.mjs

Preconditions:

- `verify.mjs doctor` が `doctor: OK` を出す。
- パネルは閉じている（ジャーニーの開始時は常に閉じている）。

- **英単語以外は無視する。** `#ja`（`単語`）をダブルクリックする。`verify.mjs run select-word` の 1 項目目で、パネルのページが存在しないことを確かめる。
- **閉じた状態から開く。** `#ubiquitous` をダブルクリックする。パネルが開き、`#word` が `ubiquitous` になる。
- **表示を切り替える。** `#idempotent` をダブルクリックする。`#word` が `idempotent` になる。
- **証跡。** `select-word-page.png` と `select-word-panel.png` に、最後の状態が残る。

## Gotchas

- `select-icon` はこのスキルでは操作できない。puppeteer はツールバーのアイコンをクリックできない。未確認と報告し、必要ならユーザーに普段の Chrome で確かめてもらう（2026-10-18 に確認済み）。
- パネルが開くのを待つ間隔は 1.2 秒に固定している。遅いマシンで失敗したら、まず `verify.mjs` の `wait(1200)` を疑う。
- リンクの中の語は、ダブルクリックしても選択されない。1 回目のクリックでリンク先に移動するので、拡張では扱わない。試験用ページにリンクの中の語を置かない。
