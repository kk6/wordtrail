# 単語を選ぶ

英語のページで単語をダブルクリックすると、タブの右側のサイドパネルにその単語が表示される。パネルが閉じているときはパネルを開かず、最後の単語を覚えておき、次に開いたときに出す。英単語 1 語でない選択（日本語、数字、複数の語）では何も起きない。

## Sub-features

- `select-remember` は、パネルが閉じた状態のダブルクリックではパネルを開かず、次に開いたときに最後の単語を出す。
- `select-switch` は、パネルが開いた状態で別の単語をダブルクリックすると、表示を切り替える。
- `select-ignore` は、英単語 1 語でない選択を無視し、覚えている単語を上書きしない。
- `select-icon` は、ツールバーのアイコンでパネルを開く。

## How to get to it (user POV)

- 読んでいるページで単語をダブルクリックする。
- ツールバーの Wordtrail のアイコンをクリックする。
- Chrome のサイドパネルのメニューで Wordtrail を選ぶ。

## Driving it with verify.mjs

Preconditions:

- `verify.mjs doctor` が `doctor: OK` を出す。
- パネルは閉じている（ジャーニーの開始時は常に閉じている）。

- **閉じた状態では開かない。** `#ubiquitous` をダブルクリックする。`verify.mjs run select-word` の 1 項目目で、パネルのページが存在しないことを確かめる。
- **英単語以外は無視し、最後の単語を出す。** `#ja`（`単語`）をダブルクリックしてから、パネルのページを開く。`#word` が `ubiquitous` になる。
- **表示を切り替える。** `#idempotent` をダブルクリックする。`#word` が `idempotent` になる。
- **証跡。** `select-word-page.png` と `select-word-panel.png` に、最後の状態が残る。

## Gotchas

- `select-icon` とサイドパネルのメニューは、このスキルでは操作できない。puppeteer はツールバーのアイコンをクリックできず、CDP の `userGesture` で呼んだ `sidePanel.open()` もユーザー操作として扱われない。そこで `openPanel` は `panel.html` を普通のタブで開く。確かめられるのは、覚えた単語をパネルのページが出すところまでで、サイドパネルが開くことは未確認と報告する（アイコンは 2026-10-18 に普段の Chrome で確認済み）。
- ダブルクリックの後に待つ間隔は 1.2 秒に固定している。遅いマシンで失敗したら、まず `verify.mjs` の `wait(1200)` を疑う。
- リンクの中の語は、ダブルクリックしても選択されない。1 回目のクリックでリンク先に移動するので、拡張では扱わない。試験用ページにリンクの中の語を置かない。
