# Wordtrail の検証マップ

このフォルダは、Wordtrail のユーザーから見える挙動を確かめるための手順の置き場で、機能が増えたらここも更新する。拡張を動かす前にこの索引を読み、該当する機能のファイルを手順として使う。

## 前提

- `verify.mjs doctor` が `doctor: OK` を出し、拡張の ID が `hhaojdoimahnlfholdnfhgiiolchgabl` になっている。
- どのジャーニーも、空のプロファイルと、`fixtures/article.html` を開いたタブから始まる。
- このスキルが起動していない Chrome は操作しない。

## 操作のきまり

- 操作は `verify.mjs run <journey>` で行う。1 回の実行で Chrome の起動から片付けまでを行う。
- 試験用ページの要素は `id` で指定し、パネルの表示は `#word`、`#meanings`（Wiktionary の欄）、`#note`（メモ）、`#sentence`、`#url` で読む。
- ダブルクリックは本物のマウス操作で行う。`page.evaluate` で作ったイベントは使わない。

## 証跡と未確認の報告

- 確かめた項目と合否は `result.json` に、操作後のページとパネルは PNG で残す。
- ジャーニーで操作できない入口（ツールバーのアイコンなど）は「未確認」と報告し、別の入口で確かめたことを、その入口の確認として扱わない。
- 前提が満たせずに失敗したときは、ジャーニーを弱めずに不合格として報告し、理由を機能のファイルの `Gotchas` に書く。

## 機能のファイルの形

各ファイルは、H1 の機能名と、ユーザーから見える挙動を説明する 1 段落で始まる。その後に、次の 4 つの H2 をこの順に置く。

1. `Sub-features`。挙動ごとに短い ID と 1 行の説明。
2. `How to get to it (user POV)`。ユーザーがその機能に触れる入口をすべて。
3. `Driving it with verify.mjs`。`Preconditions:` から始め、操作、コマンド、見えるべき結果を組にして書く。
4. `Gotchas`。検証を無駄にしたり、結果を無効にしたりする落とし穴。

## 機能

- [単語を選ぶ](./select-word.md) は、ダブルクリックした単語がパネルに出るまでと、閉じているときに覚えておくことを扱う。
- [文脈を取る](./sentence.md) は、選んだ単語を含む 1 文とページの URL がパネルに出ることを扱う。
- [意味を入れる](./meanings.md) は、小文字の見出し語と、Wiktionary から引いた意味がパネルに出ることを扱う。
- [書き換えて保存する](./save.md) は、見出し語を直してメモを書いて保存すると、単語帳にその内容と Wiktionary の意味と文脈が入ることを扱う。
- [登録済みの単語にまた出会う](./registered.md) は、保存した単語を別のページでダブルクリックすると、保存した内容が出て、文脈が重ならずに増えることを扱う。
- [見出し語を登録済みの語に変える](./rename.md) は、見出し語を別の登録済みの語に書き換えると、その語の内容に切り替わり、意味とメモが上書きされないことを扱う。
- [書き換え中の内容を守る](./unsaved.md) は、書き換えると未保存と出て、そのまま別の語をダブルクリックすると確認が出ることを扱う。
- [保存した単語が残る](./persist.md) は、拡張の読み込み直しと Chrome の再起動の後も、保存した単語が残ることを扱う。
- [一覧と削除](./list.md) は、登録した単語が新しい順に並び、開くと意味と文脈が出て、確認の後に削除できることを扱う。
- [書き出しと読み込み](./backup.md) は、単語帳を 1 つの JSON ファイルに書き出し、拡張を入れ直した後でもそのファイルから元に戻せること、メモができる前の版 1 のファイルも読めることを扱う。
- [メモを書く](./memo.md) は、自由に書けるメモが単語と一緒に残り、Wiktionary の欄は書き換えられないことを扱う。
- [見出し語を直して引き直す](./relookup.md) は、見出し語の欄を離れたときだけ、直した語で Wiktionary を引き直すことを扱う。
- [メモの前の単語を移す](./migrate.md) は、メモができる前に保存した単語の、品詞のない意味がメモに移ることを扱う。
- [読み上げる](./speak.md) は、見出し語と文脈の文の横のボタンで、その語や文を英語として読み上げることを扱う。
- [iframe の中の語を選ぶ](./iframe.md) は、埋め込まれた iframe の中の語でも、単語と文とタブの URL がパネルに出ることを扱う。
- [拡張の ID を固定する](./stable-id.md) は、読み込み直しても単語帳が失われないための前提を扱う。

機能を足したら、ここにファイルを足す。
