# Wordtrail

英語のページを読みながら、知らない単語を自分の単語帳に貯めていく Chrome 拡張です。読んでいるタブの右側に単語帳を開いておき、単語をダブルクリックすると、その単語が単語帳に出ます。意味は Wiktionary から自動で入り、その単語が出てきた文と URL も一緒に保存されます。英辞郎のテキストデータを持っていれば、取り込んで日本語の訳も出せます。訳や覚え方など、自分の言葉はメモの欄に書きます。

自分ひとりで使うための拡張なので、アカウント登録もサーバーもありません。データはこの PC の Chrome の中だけに保存されます。

## インストールする

Chrome Web Store には公開していません。手元のフォルダから読み込みます。

1. このリポジトリを手元にクローンするか、ダウンロードして展開します。
2. Chrome のアドレスバーに `chrome://extensions` と入力して開きます。
3. 右上の **デベロッパー モード** をオンにします。
4. **パッケージ化されていない拡張機能を読み込む** をクリックし、手順 1 のフォルダの中にある `extension` フォルダを選びます。
5. ツールバーのパズルのアイコンをクリックし、Wordtrail の横のピンをクリックします。

ツールバーに Wordtrail のアイコンが表示されれば、インストールは完了です。

コードを更新したときは、`chrome://extensions` の Wordtrail にある再読み込みボタンをクリックします。フォルダを読み込み直しても、単語帳の内容は消えません。

メモの欄ができる前（0.1.0 まで）に保存した単語は、更新後の最初の再読み込みで新しい形に移ります。意味の欄に品詞の行を書かずに入力したものはメモに移り、品詞のある意味は Wiktionary の欄に残ります。何も消えません。

## 使い方

### 知らない単語を登録する

記事を読んでいて知らない単語が出てきたときの手順です。

1. 読み始める前に、ツールバーの Wordtrail のアイコンをクリックします。タブの右側に単語帳のパネルが開きます。Chrome のサイドパネルのメニューから Wordtrail を選んでも開けます。
   - パネルが閉じているときにダブルクリックしても、パネルは開きません。コピーのためのダブルクリックで読書が遮られないようにするためです。後でパネルを開くと、最後にダブルクリックした単語が出ます。
2. 知らない単語をダブルクリックします。パネルに新規登録の画面が出ます。
3. 入力済みの内容を確かめます。
   - **見出し語** には、ダブルクリックした語が小文字で入っています。
   - **Wiktionary** には、Wiktionary から取得した意味が品詞ごとに出ています。読むだけの欄で、書き換えられません。
   - **文脈** には、その語を含む文と、ページの URL が入っています。
4. 必要なら、見出し語を直し、メモを書きます。
   - たとえば `Running` をダブルクリックしたときに `run` として登録したければ、見出し語を `run` に直します。欄を離れると、Wiktionary の欄が `run` で引き直した意味になります。入力の途中では引き直しません。
   - 直した見出し語がすでに登録してある語なら、欄を離れたときに、その語の保存内容に切り替わります。保存すると、その語の意味とメモは残したまま、今の文が文脈に足されます。
   - **メモ** には、訳、覚え方、気づいたことなどを自由に書きます。Wiktionary の説明に補足したいことも、ここに書きます。
5. **保存** をクリックします。

Wiktionary に見つからない語の場合、Wiktionary の欄に見つからなかったと出ます。調べたことはメモに書いてから保存します。

見出し語や文の横の ▶ をクリックすると、その語や文を英語で読み上げます。Mac に入っている Samantha の声で読むので、インターネット接続は要りません。Samantha がないときは、Chrome が選んだ英語の声で読みます。これまでの文脈と、一覧の見出し語にも ▶ があります。一覧の ▶ を押しても、その単語の編集画面には移りません。

文の意味がなんとなく取れていて、読み進めるのを優先したいときは、意味を読まずに **保存** だけクリックしても構いません。あとで一覧から見返せます。

### 前に登録した単語にまた出会う

別の記事で、登録済みの単語をまたダブルクリックすると、パネルには新規登録ではなく、保存してある内容が出ます。Wiktionary は引き直さず、登録したときの意味が出ます。

このとき、今読んでいる文と URL が文脈の一覧に追加されます。同じ文がすでにあれば追加されません。文脈の数は、その単語が何回わからなかったかの記録になります。

メモを書き足したいときは、その場で編集して **保存** をクリックします。

見出し語の大文字と小文字は区別しません。ただし活用形は別の単語として扱います。`ran` で登録した単語は、`run` をダブルクリックしても登録済みになりません。

### 英辞郎の訳を出す

英辞郎のテキストデータ（購入した `EIJIRO144-10.TXT` のような Shift JIS のファイル）を取り込むと、パネルの Wiktionary の欄の上に「英辞郎」の欄が出ます。英辞郎のデータは拡張に含まれていないので、自分で購入したファイルを使います。

1. パネル上部の **一覧** をクリックします。
2. **英辞郎を取り込む** をクリックし、英辞郎のテキストファイルを選びます。
3. 取り込みが終わるまで待ちます。取り込み中はボタンが押せず、取り込み中だと出ます。Ver.144.10（146MB）では約 11 秒かかりました。
4. 終わると、`英辞郎：275,640 語（EIJIRO144-10.TXT）` のように、語数とファイル名が出ます。

英辞郎の欄は読むだけで、書き換えられません。訳が長いときは、ラベルの **英辞郎** をクリックすると欄を畳めます。畳んだ欄は、別の単語に移っても、パネルを開き直しても畳んだままです。もう一度クリックすると開きます。

- 見出し語を大文字と小文字を区別せずに引き、訳を品詞ごとに番号付きで並べます。綴りが違う見出し語（`us` で引いたときの `US` など）には、元の綴りを添えます。
- 補足（◆以降）、例文、発音は出しません。`colour` の `＝<→color>` のような参照の行は出します。
- 見出し語を直して欄を離れると、英辞郎の欄も直した語で引き直します。
- 訳は単語と一緒には保存されず、書き出すファイルにも入りません。開くたびに、取り込んだデータから引きます。
- 取り込んだデータは、Chrome を再起動しても残ります。別の版のファイルを取り込み直すと、前のデータは丸ごと置き換わります。英辞郎でないファイルを選んだときは、失敗したと出て、前のデータが残ります。

英辞郎のファイルは、このリポジトリのフォルダに置かないでください。英辞郎の利用条件では、購入者以外が使える状態にすることが禁じられています。誤ってフォルダにコピーしても、`EIJIRO` で始まり数字で終わる `.TXT` のファイルは `.gitignore` で git の追跡から外れます。

### 単語帳を見返して、書き出しておく

パネル上部の **一覧** をクリックすると、登録した単語が新しい順に並びます。各行には見出し語と、`文脈 3` のような文脈の件数が出ます。

行をクリックすると、その単語の編集画面に移ります。

- 英辞郎の訳、Wiktionary の意味、メモ、これまでの文脈が出ます。
- 書き換えられるのはメモだけです。見出し語は書き換えられません。
- **保存** をクリックすると、メモだけが書き換わります。文脈は増えません。
- 不要な単語は **削除** で消せます。確認のダイアログで承認すると削除され、一覧に戻ります。削除のボタンは、一覧から開いたときだけ出ます。
- パネル上部の **一覧** をクリックすると、一覧に戻ります。

一覧の **戻る** をクリックすると、最後にダブルクリックした単語が出ます。メモを書き換えて保存していないときに、一覧の行や **戻る** をクリックすると、変更を捨てるかの確認が出ます。

単語帳のデータは、拡張を `chrome://extensions` から削除すると一緒に消えます。定期的に書き出して、バックアップを取っておきます。

- 一覧画面の **書き出し** をクリックすると、全データが 1 つの JSON ファイルとしてダウンロードされます。
- 一覧画面の **読み込み** をクリックしてそのファイルを選ぶと、単語帳が復元されます。今ある単語帳は、ファイルの内容で丸ごと置き換わります。置き換える前に確認のダイアログが出ます。
- メモの欄ができる前（0.1.0 まで）に書き出したファイルも読み込めます。読み込むときに、再読み込みのときと同じく、品詞のない意味をメモに移します。

書き出した JSON ファイルは、Anki など他のツールに単語を移すときにも使えます。

## できないこと

- 英語以外の言語には対応していません。
- 意味は Wiktionary の英語の説明です。日本語訳は、英辞郎を取り込んだときだけ英辞郎の欄に出ます。訳をメモに自動で写すことはしません。
- Wiktionary の説明が間違っていたり分かりにくかったりしても、パネルでは直せません。補足はメモに書きます。
- 登録できるのは、ダブルクリックで選べる 1 語だけです。熟語は登録できません。英辞郎も、1 語の見出し語だけを取り込みます。
- 活用形を原形に直して引くことはしません。英辞郎の欄では `ran` の項目に `runの過去形` と出るので、そこから原形をたどります。
- 意味の取得には [Wiktionary](https://en.wiktionary.org/) の API を使うため、インターネット接続が必要です。つながらないときや、10 秒たっても応答がないときは、Wiktionary の欄に見つからなかったと出ます。
- 他の PC との同期はしません。別の PC で使うときは、書き出したファイルを読み込みます。
