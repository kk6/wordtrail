# ADR-0004: 一覧から単語を開いて編集し、英辞郎の欄を折り畳めるようにする

## Status

proposed

## Date

2026-10-24

## Context (Why)

ADR-0001 では、一覧を「新しく登録した順の表示と削除だけ」にした。一覧で単語を開くと、その場で意味、メモ、文脈が出るが、書き換えはできない。メモを直すには、その単語が出てくるページでもう一度ダブルクリックするしかない。

ADR-0003 で、英辞郎の訳をパネルの編集画面に出した。2026-10-24 に普段の Chrome で本物のデータを使ったところ、二つのことがわかった。一覧で単語を開いても、英辞郎の訳は出ない。また、`run` のような語では訳がとても長く、Wiktionary の欄やメモが画面の下に押しやられる。

一覧にも英辞郎の訳を足すと、同じ単語を一覧と編集画面の 2 か所で、別々の形で出すことになる。長い訳を一覧に収める工夫も別に要る。一覧から編集画面に移れるようにすれば、単語を見返す場所が編集画面の 1 か所にまとまる。英辞郎の訳もメモの編集も、そこで済む。

ただし、今の編集画面は「今読んでいる文」があることを前提にしていて、保存すると必ずその文を文脈に足す。一覧から開いた単語には今読んでいる文がないので、文脈を足さずに保存できる形が要る。

この ADR は、ADR-0001 の「一覧は表示と削除だけ」を変える。

## Intent (What)

受け入れ条件:

1. 一覧の各行には、見出し語、読み上げのボタン、文脈の件数だけを出す。
   - 行をクリックすると、その単語の編集画面に移る。
   - 読み上げのボタンを押しても、編集画面には移らない。
2. 一覧から開いた編集画面には、英辞郎、Wiktionary、メモ、これまでの文脈を出す。今読んでいる文の欄は出さない。
3. 一覧から開いた編集画面では、見出し語を書き換えられない。書き換えられるのはメモだけにする。
4. 一覧から開いた編集画面で保存すると、メモだけが書き換わる。文脈の件数は変わらない。保存した後も編集画面のままにする。
5. 一覧から開いた編集画面にだけ、削除のボタンを出す。
   - 確認のダイアログで承認したときだけ削除し、一覧に戻る。
   - ダブルクリックで開いた編集画面には、削除のボタンを出さない。
6. 一覧から開いた編集画面のナビのボタンは「一覧」にし、押すと一覧に戻る。一覧の「戻る」は、これまでどおり、最後にダブルクリックした単語を、保存されている内容で表示する。
7. 編集画面の内容が別の単語に置き換わるとき、未保存の変更があれば確認を出す。
   - 対象は、一覧の行のクリック、ページでのダブルクリック、一覧の「戻る」の三つ。
   - 一覧に移るだけでは、確認を出さない。
8. 英辞郎の欄は、ワンクリックで畳んだり開いたりできる。
   - 最初は開いている。
   - 畳むと、別の単語に移っても、パネルを開き直しても、畳んだままになる。開いたときも同じく、開いたままになる。

## Non-goals

- 見出し語の名前の変更（文脈ごと別の見出し語に移すこと）。一覧から開いた単語の見出し語の誤りを直したくなったら検討する。
- 一覧でまとめて削除すること（Gmail の受信トレイのように、削除のモードでだけチェックボックスを出す形）。1 語ずつ消すのが手間になったら検討する。
- Wiktionary の欄の折り畳み。長くて困ったら、英辞郎の欄と同じ形で足す。
- 一覧の検索、並べ替え、タグ付け。ADR-0001 のまま対象外にする。

## Constraints

- 単語帳の保存の形と、書き出すファイルの形を変えない。書き出しの版は 2 のままにする。
- 外部への通信を増やさない。
- 英辞郎の欄の開閉の状態は、単語帳にも書き出すファイルにも入れない。

## Alternatives Considered

- **一覧で開く欄はそのままにして、中に「編集」のボタンを置く**: 同じ単語を、一覧と編集画面の 2 通りで出すことになる。一覧に英辞郎の訳を足すなら、長い訳を一覧に収める工夫も要る。
- **一覧の行に削除のボタンを残す**: 行の中に、クリックで別のことが起きる場所が二つでき、押し間違えやすい。
- **ダブルクリックで開いた登録済みの単語にも、削除のボタンを出す**: 読書中に単語を消した後に、どの画面を出すかが決まらない。
- **一覧から開いたときも見出し語を書き換えられるようにし、今と同じく未登録の語なら新しい単語として保存する**: 文脈が 0 件の単語ができてしまう。
- **一覧から開いたときも、今読んでいる文の欄を出す**: 一覧から開いた単語とは関係のない文が、文脈に足されてしまう。
- **英辞郎の欄を、単語ごとに毎回開く**: 長い訳を、単語を開くたびに畳むことになる。
- **英辞郎の欄を、最初から畳んでおく**: 読みながら訳をすばやく見る、という ADR-0003 の目的に反する。

## Consequences

ポジティブ:

- 単語を見返す場所が編集画面の 1 か所にまとまる。一覧からも英辞郎の訳が見られる。
- ページに戻らなくても、一覧からメモを書き足せる。
- 英辞郎の訳が長い語でも、Wiktionary の欄とメモにすぐ届く。

ネガティブ:

- 一覧だけでは、単語の意味が見えなくなる。意味を見るには、1 語ずつ編集画面を開く。
- 削除するには、一覧で単語を開いてから削除のボタンを押す。1 回クリックが増える。
- 一覧から開いた単語では、見出し語の誤りを直せない。
- 編集画面に、ダブルクリックで開いたときと一覧から開いたときの二つの状態ができる。保存、削除、ナビのボタンの動きが状態ごとに変わる。
