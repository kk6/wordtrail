# ADR-0003: 英辞郎の訳を、利用者が取り込んだデータから読むだけで出す

## Status

accepted

## Date

2026-10-24

## Context (Why)

ADR-0001 では、日本語訳の自動入力を対象外にした。翻訳 API のキーの管理と無料枠の上限が負担になるためだった。その後、英辞郎のテキストデータ（Ver.144.10）を購入した。手元のデータから引くなら、API のキーも無料枠も要らない。英英の定義だけでは、読みながら意味をすばやくつかみにくい場面があり、日本語の訳が欲しい。

ADR-0002 で、辞書から取った内容は読むだけにし、出典の名前を欄に付けると決めた。英辞郎の訳も、この決まりに沿って「英辞郎」という読むだけの欄として並べる。

英辞郎のデータは再配布できない。利用条件（2026-10-18 に購入ページで確認）では、使えるのは購入者本人だけで、第三者が使える状態にするのは禁止されている。このリポジトリは public なので、データを 1 度でも push すれば禁止事項に当たる。push の後に CI で確かめる方法では手遅れになる。そのため、データがリポジトリのフォルダに入る経路そのものを作らない。

元のファイルは `EIJIRO144-10.TXT`（Shift JIS、153MB、約 258 万行）。1 語の見出し語に絞ると約 28 万語になり、パネルから引くのに十分な量に収まる。熟語はダブルクリックでは拾えないので、絞っても困らない。

この ADR は、ADR-0001 の「v0.1 の対象外」のうち「日本語訳の自動入力」を変える。訳は手元のデータから表示するだけで、利用者が書く欄には入力しない。

## Intent (What)

受け入れ条件:

1. 単語帳の一覧の画面で、利用者が英辞郎のテキストファイルを選んで取り込める。
   - 取り込み中は、取り込みのボタンを押せなくなり、取り込み中だとわかる表示が出る。
   - 取り込み終わると、取り込んだ語数とファイル名が表示される。
   - 取り込み直すと、前のデータはすべて新しいデータに置き換わる。
   - 英辞郎の行が 1 行もないファイルを選んだときや、途中で失敗したときは、前のデータがそのまま残り、失敗したことが表示される。
2. 取り込むのは、ダブルクリックで拾える形の見出し語（英字だけの 1 語。ハイフンとアポストロフィを含む）だけにする。
3. パネルに「英辞郎」の欄を、Wiktionary の欄より上に出す。利用者は書き換えられない。
4. 英辞郎の欄は、パネルの見出し語で引いた結果を出す。
   - 大文字と小文字を区別せずに、完全に一致する見出し語を引く。活用形を原形に直す処理はしない（`ran` なら、英辞郎にある `ran` の項目を出す）。
   - 引くタイミングは Wiktionary の欄と同じにする。見出し語を直したときも、直した語で引き直す。
5. 訳は品詞ごとにまとめ、品詞ごとに番号付きで並べる。
   - 補足（`◆` 以降）、例文（`■・` 以降）、発音やレベルなどのメタ情報の行は出さない。
   - 参照の行（`＝<→color>` など）は出す。
   - 引いた語と綴りが違う見出し語（`us` で引いたときの `US` など）には、元の綴りを添える。
6. 取り込む前は、英辞郎の欄を出さない。取り込んだ後に見つからない語では、欄に見つからなかったことを出す。
7. 英辞郎の訳は単語と一緒に保存しない。書き出したファイルにも入らない。

## Constraints

- 英辞郎のデータ（元のファイルも、変換したものも）を、リポジトリのフォルダに置かない。拡張に同梱しない。
- テストと Chrome での検証には、自作の数行のサンプルを使う。本物のデータは 1 行も含めない。
- 誤ってコピーした場合に備えて、英辞郎のファイル名を git の追跡から外す。
- 外部への通信を増やさない。取り込みも引くのも手元だけで完結する。
- 取り込みのときに、153MB のファイル全体を一度にメモリへ読み込まない。

## Alternatives Considered

- **Node のスクリプトで JSON に変換し、`extension/` の下の git 管理外のフォルダに置く**: もともと `docs/ideas.md` に書いていた案。`.gitignore` の書き間違いや `git add -f` が 1 回あれば、public リポジトリに push されて規約違反になる。CI で確かめても、気づくのは push の後になる。
- **全項目（熟語を含む約 236 万語）を取り込む**: 保存する量が 6 倍以上になる。ダブルクリックで拾えない熟語は、パネルから引く場面がほぼない。
- **活用形を原形に直してから引く**: ADR-0001 で対象外にしたまま。英辞郎には `ran → runの過去形` のような項目があり、それを見れば原形をたどれる。
- **英辞郎の訳を単語と一緒に保存する**: 書き出しから外す処理と、書き出しの版を上げる処理が要る。データは手元にあるので、毎回引いても困らない。
- **補足、例文、発音も出す**: パネルが長くなり、訳をすばやく読めなくなる。欲しくなったら、後から折りたたみで足せる。
- **取り込んだデータを消すボタンを作る**: 使う場面がまだない。取り込み直しで置き換えられる。

## Consequences

ポジティブ:

- 読みながら、日本語の訳を同じパネルで見られる。
- データがリポジトリに入る経路がないので、規約違反の事故が構造の上で起きない。
- 辞書から取った内容は読むだけ、という ADR-0002 の決まりがそのまま保たれる。
- 外部の API に頼らないので、接続できないときも訳を見られる。

ネガティブ:

- Chrome ごとに、利用者が自分で 1 回取り込む必要がある。拡張を入れ直したときも取り込み直しになる。
- 熟語や活用形は、英辞郎の欄では直接引けない。
- 英辞郎の新しい版が出ても、自動では更新されない。手で取り込み直す。
- 取り込み処理（ファイルを少しずつ読み、Shift JIS から変換する処理）が拡張に増える。
